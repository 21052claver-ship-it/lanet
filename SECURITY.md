# Seguretat

Comunica vulnerabilitats amb Report a vulnerability a la pestanya Security del repositori. Evita publicar dades d’usuaris, cookies, secrets o exemples d’explotació contra l’aplicació real en issues públics.

Revisem dependències amb alertes de GitHub i Dependabot. CI usa fixtures locals, sense credencials de producció. Les publicacions requereixen codi net, commit remot coincident i CI verda.
