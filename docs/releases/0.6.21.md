Mode focus amb selector visible Amb Pomodoro / Estudi lliure. El mode lliure conserva el fons Clar/Bosc/Nit i la música opcional; pausa el temporitzador i en conserva fase, temps i sessió. Tornar a Pomodoro no el reprèn fins a una acció explícita. Preferències locals per usuari, controls musicals visibles inicialment i reproductor compartit. Alarma i sons de ruleta actius per defecte, amb silenci i volum zero desats respectats.

El rellotge deixa de tenir un interval quan està pausat. El cercle podia encongir-se amb les opcions obertes i tapar Comença; es conserva l’alçada del contingut i el botó continua accessible. El mode lliure compacte mostra selector, personalització i controls musicals en paisatge. El títol segueix el color del tema, també en Nit; els primers selectors Clar/Anell conserven el nom accessible amb camps neutres.
