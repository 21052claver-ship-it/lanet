L’auditoria cobreix navegació, formularis, gestió, rols, comptes/sessions, propostes/avisos, plusos/calendari, retirada de contingut, recuperació de plantilles, sortida amb reintent, pujades, CSV, música, pastisseria i compatibilitat. [Matriu de famílies i inventari](../PLA-AUDITORIA-FUNCIONAL.md).

Les proves generals s’han adaptat a la revisió de delegats, identificadors privats ocults, límits d’abús, càrrega diferida i capçalera mòbil amb files múltiples. La CI incorpora les suites funcionals, retenció, pastisseria, música, activitats de notes, pujades i API general.

La CI va descobrir un segon error real de represa musical a WebKit/Linux. Reproduït localment: després d’un salt de posició, l’àudio avançava però play() quedava pendent i la UI continuava carregant. Corregit amb confirmació per avanç real, cancel·lació i neteja sense timers/peticions. La prova de navegador original es conserva; 13 escenaris WebKit/Linux i 39 Windows correctes sobre la correcció. El registre de CI conserva els intents.

Tag/release immutable i digest del rebut contrastats amb GitHub. Commit, estat de desplegament, domini actiu, lanet.pages.dev, callback Google i bindings D1/R2 confirmats amb les API dels proveïdors. Cap migració ni desplegament del manteniment privat; worker i SQL de producció no han canviat. Cap regal o reinici.

Totes les proves funcionals són locals, amb identitats i fitxers ficticis. Chrome i Edge s’han executat instal·lats; iPhone/Pixel són simulacions. No s’ha visitat l’aplicació pública ni s’ha provat un login Google real o dispositius físics. L’inventari és una correspondència de famílies amb recorreguts, no una garantia de totes les combinacions possibles.

Rebuts, logs i captures privats a output/functional-audit-0.6.16 i output/releases/0.6.17. El tancament documental queda en branca local per a la pròxima tanda, sense nova pujada ni desplegament.
